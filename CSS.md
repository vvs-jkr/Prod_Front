### 1. CSS селекторы смежных элементов

**Вопрос:** Как выбрать все абзацы `<p>`, которые находятся после любого заголовка `<h2>` на одном уровне вложенности?

-   `h2 ~ p`
-   `.content > p`
-   `p ~ h2`
-   `h2 + p`
-   `h2 p`

**Правильный ответ:** `h2 ~ p`

**Объяснение:** Селектор `h2 ~ p` выбирает все элементы `<p>`, которые являются соседними элементами (siblings) и следуют после элемента `<h2>` на том же уровне вложенности. Символ `~` называется "общий селектор соседних элементов" и выбирает все подходящие элементы, следующие за указанным элементом, в отличие от `+`, который выбирает только непосредственно следующий элемент.

### 2. Сброс стилей дочерних элементов

**Вопрос:** Какой способ наиболее надёжный для сброса всех стилевых свойств дочернего элемента `.box > div`, кроме тех, что наследуются от `.box`?

-   `.box > div { revert: all; }`
-   `.box > div { all: initial; }`
-   `.box > div { font: unset; }`
-   `.box > div { all: none; }`
-   `.box > div { all: unset; }`

**Правильный ответ:** `.box > div { all: unset; }`

**Объяснение:** Свойство `all: unset` сбрасывает все CSS-свойства элемента до их наследуемых значений (если свойство наследуется) или до начальных значений (если не наследуется). Это наиболее надёжный способ очистки стилей, поскольку `unset` учитывает природу каждого свойства. `initial` устанавливает все свойства в начальные значения, игнорируя наследование, а `revert` возвращает к браузерным стилям.

### 3. Адаптивные изображения с тегом img

**Вопрос:** Как добавить логотип (размеры исходного изображения 40 x 40 пикселей) на страницу через тег `img` для адаптивной верстки?

-   Задать `flex-basis`
-   Сделать `img` строчным тегом
-   Сделать `img` блочным тегом
-   Ограничить ширину и высоту
-   Дополнительных действий совершать не нужно

**Правильный ответ:** `Дополнительных действий совершать не нужно`

**Объяснение:** Если изображение уже имеет нужные размеры (40x40 пикселей), то для простого логотипа дополнительных действий не требуется. Тег `<img>` по умолчанию отображает изображение в его натуральном размере. Для адаптивности может потребоваться только добавление `max-width: 100%` если нужно, чтобы изображение масштабировалось на очень маленьких экранах, но для логотипа фиксированного размера это обычно не критично.

### 4. Динамическое добавление CSS через JavaScript

**Вопрос:** Когда может быть оправдано динамическое добавление CSS через JavaScript?

-   Когда нужно изменять стили в зависимости от событий
-   Когда проект требует строгого разделения логики и представления
-   Когда нужно сократить размер финального HTML-файла
-   Когда необходимо обеспечить поддержку всех старых браузеров
-   Когда проект не использует JavaScript вовсе

**Правильный ответ:** `Когда нужно изменять стили в зависимости от событий`

**Объяснение:** Динамическое добавление CSS через JavaScript оправдано когда нужно изменять стили в ответ на пользовательские действия, состояние приложения или другие события, которые невозможно предусмотреть в статическом CSS. Например, изменение темы, адаптация под размер контента, условная стилизация на основе данных. В остальных случаях предпочтительнее использовать статический CSS для лучшей производительности и разделения ответственности.

### 5. Адаптивные отступы с CSS функциями

**Вопрос:** Как задать адаптивный отступ слева, который учитывает и фиксированный отступ, и размер экрана?

-   Использовать `padding-left: 5%` и `padding-inline-start: 2rem`
-   Использовать `padding-left: calc(2rem + 5vw)`
-   Использовать `padding-left: clamp(2rem, 5vw, 10rem)`
-   Использовать `padding-left: 2rem` и задать `margin-left: 5vw`
-   Использовать `padding-left: auto` в сочетании с `margin-left: 5vw`

**Правильный ответ:** `Использовать padding-left: clamp(2rem, 5vw, 10rem)`

**Объяснение:** Функция `clamp()` идеально подходит для создания адаптивных отступов, поскольку позволяет установить минимальное значение (2rem), предпочтительное адаптивное значение (5vw, которое зависит от ширины окна просмотра) и максимальное значение (10rem). Это обеспечивает отступ, который масштабируется с размером экрана, но имеет разумные ограничения сверху и снизу.

### 6. Равномерное распределение элементов в Flexbox

**Вопрос:** Как равномерно распределить три блока по ширине контейнера с отступами между ними в Flexbox?

-   Использовать `display: flex` и `gap: auto`
-   Использовать `display: flex; align-items: stretch`
-   Использовать `display: flex; justify-content: center` и `margin`
-   Назначить `width: 33.3%` каждому элементу без flex-контейнера
-   Применить `display: flex; justify-content: space-between`

**Правильный ответ:** `Применить display: flex; justify-content: space-between`

**Объяснение:** Свойство `justify-content: space-between` в flex-контейнере равномерно распределяет элементы по главной оси, размещая первый элемент в начале, последний в конце, а остальные элементы распределяются с равными промежутками между ними. Это идеальное решение для равномерного распределения трех блоков с автоматическими отступами между ними без необходимости вручную задавать ширину или отступы.

### 7. Оси в Flexbox

**Вопрос:** Какая комбинация осей используется Flexbox для размещения элементов?

-   Верхняя и нижняя ось
-   Левый и правый поток
-   Только горизонтальная ось
-   Основная и вспомогательная ось
-   Статическая и абсолютная ось

**Правильный ответ:** `Основная и вспомогательная ось`

**Объяснение:** Flexbox использует две оси для размещения элементов: главную ось (main axis) и поперечную ось (cross axis), которую также называют вспомогательной. Главная ось определяется свойством `flex-direction` и может быть горизонтальной или вертикальной. Поперечная ось всегда перпендикулярна главной. Свойство `justify-content` управляет выравниванием по главной оси, а `align-items` - по поперечной оси.

### 8. Псевдоэлементы для добавления контента

**Вопрос:** Как добавить иконку после текста кнопки без изменения HTML-разметки?

-   Использовать `::before` без `content`
-   Применить `:focus-visible`
-   Задать `::marker` содержимое
-   Добавить `::after + content`
-   Применить `:has()` к кнопке

**Правильный ответ:** `Добавить ::after + content`

**Объяснение:** Псевдоэлемент `::after` в сочетании со свойством `content` позволяет добавить контент после элемента без изменения HTML. Например: `button::after { content: "→"; margin-left: 5px; }`. Это добавит стрелку после текста каждой кнопки. Псевдоэлемент `::before` добавляет контент перед элементом, а не после. Свойство `content` обязательно для работы псевдоэлементов `::before` и `::after`.

### 9. Псевдоклассы для выбора первых элементов

**Вопрос:** Какой псевдокласс позволяет применить стиль к первому абзацу внутри родительского элемента, только если он действительно является первым элементом внутри родителя?

-   `p:nth-child(1)`
-   `p:first-of-type`
-   `p:only-child`
-   `p:first-child`
-   `p:first-line`

**Правильный ответ:** `p:first-child`

**Объяснение:** Псевдокласс `:first-child` выбирает элемент, который является первым дочерним элементом своего родителя. `p:first-child` применит стиль только к абзацу, который действительно является первым элементом внутри родителя. В отличие от `:first-of-type`, который выбирает первый элемент определенного типа, `:first-child` требует, чтобы элемент был первым среди всех дочерних элементов, независимо от их типа.

### 10. CSS анимации и задержки

**Вопрос:** Как реализовать плавное появление элемента с задержкой в 0.5 секунды при его загрузке на странице?

-   `element { animation: fadeIn ease 0s 0.5s; }`
-   `element { transition: opacity 1s 0.5s ease; }`
-   `element { animation-delay: 1s; opacity: 1; }`
-   `element { animation: ease-in fadeIn 1s 0.5s; }`
-   `element { animation: fadeIn 1s ease 0.5s forwards; }`

**Правильный ответ:** `element { animation: fadeIn 1s ease 0.5s forwards; }`

**Объяснение:** Для плавного появления элемента с задержкой нужно использовать CSS-анимацию с правильным синтаксисом: `animation: name duration timing-function delay fill-mode`. В данном случае `fadeIn` - имя анимации, `1s` - длительность, `ease` - функция плавности, `0.5s` - задержка, `forwards` - сохраняет финальное состояние анимации. Также потребуется создать keyframes для анимации fadeIn, которая изменяет opacity от 0 до 1.

### 11. 3D трансформации и перспектива

**Вопрос:** Как реализовать 3D-анимацию переворота карточки по оси X при наведении курсора с сохранением перспективы родительского контейнера?

-   Использовать `transform: skew(180deg)` без дополнительных параметров
-   Применить `perspective(1000px)` и `transform: rotateZ(180deg)`
-   Задать `transform: rotateX(180deg)` и `perspective` на карточке
-   Задать `transform: scale(2)` и `backface-visibility: hidden`
-   Применить `transform-style: flat` и `rotateX(180deg)` к карточке

**Правильный ответ:** `Задать transform: rotateX(180deg) и perspective на карточке`

**Объяснение:** Для 3D-переворота карточки по оси X нужно использовать `transform: rotateX(180deg)` для самого поворота и установить `perspective` на родительском контейнере для создания 3D-эффекта. Также полезно добавить `transform-style: preserve-3d` на контейнер и `backface-visibility: hidden` на карточку для корректного отображения. `rotateZ` поворачивает по оси Z, а не X, `scale` изменяет размер, а не поворачивает.

### 12. Оптимизация анимации для производительности

**Вопрос:** Какой способ перемещения элемента на экране считается наиболее эффективным для анимации с точки зрения производительности?

-   `padding-left: 100px`
-   `transform: translateX(100px)`
-   `top: 100px`
-   `left: 0 → 100px`
-   `margin-left: 100px`

**Правильный ответ:** `transform: translateX(100px)`

**Объяснение:** Использование `transform: translateX()` является наиболее производительным способом перемещения элементов для анимации, поскольку трансформации обрабатываются на уровне композитного слоя GPU, не вызывая reflow или repaint основного документа. Изменение свойств `left`, `top`, `margin` или `padding` заставляет браузер пересчитывать layout и перерисовывать элементы, что значительно медленнее, особенно при сложных анимациях или на мобильных устройствах.

### 13. Специфичность CSS селекторов

**Вопрос:** Какой селектор будет переопределен при конфликте правил для элемента `<a href="#" class="link" id="mainLink"></a>`?

-   `#mainLink`
-   `.link#mainLink`
-   `.link`
-   `a.link`
-   `#mainLink`

**Правильный ответ:** `.link`

**Объяснение:** В CSS специфичность селекторов рассчитывается по правилу: инлайн-стили (1000) > ID селекторы (100) > классы/атрибуты/псевдоклассы (10) > элементы/псевдоэлементы (1). В данном случае: `#mainLink` имеет специфичность 100, `.link#mainLink` имеет 110, `.link` имеет 10, `a.link` имеет 11. Селектор с наименьшей специфичностью `.link` (10) будет переопределен всеми остальными селекторами при конфликте правил.

### 14. Адаптивные изображения

**Вопрос:** Как реализовать поведение, при котором изображение всегда масштабируется по ширине контейнера, сохраняя пропорции?

-   `.responsive { object-fit: cover; width: 100vw; }`
-   `.responsive { width: 100%; height: auto; }`
-   `.responsive { position: absolute; width: 100%; }`
-   `.responsive { width: auto; height: 100%; }`
-   `.responsive { aspect-ratio: 1/1; width: 100%; }`

**Правильный ответ:** `.responsive { width: 100%; height: auto; }`

**Объяснение:** Для создания адаптивного изображения, которое масштабируется по ширине контейнера с сохранением пропорций, используется `width: 100%` (изображение занимает всю ширину родительского контейнера) и `height: auto` (высота автоматически рассчитывается для сохранения пропорций). Это классический способ создания отзывчивых изображений. `object-fit: cover` изменяет способ вписывания, но не делает изображение адаптивным по размеру контейнера.

### 15. Медиа-запросы и адаптивность

**Вопрос:** Что произойдет с карточкой, если ширина экрана будет меньше, чем 1200px?

```css
.card {
    width: 1200px;
    height: 600px;
    background-color: slateblue;
}

@media (width: 1200px) {
    .card {
        background-color: peachpuff;
        transition: all 0.3s ease 0s;
    }
}
```

-   Карточка будет пропорционально уменьшаться по ширине и высоте
-   Карточка не изменится
-   Карточка изменит цвет
-   Карточка будет менять только свою ширину в зависимости от ширины экрана
-   Запустится анимация

**Правильный ответ:** `Карточка не изменится`

**Объяснение:** Медиа-запрос `@media (width: 1200px)` применяется только когда ширина экрана точно равна 1200px. Если ширина меньше 1200px, условие медиа-запроса не выполняется, поэтому стили внутри него не применяются. Карточка сохранит базовые стили: `width: 1200px`, `height: 600px`, `background-color: slateblue`. Для адаптивности следовало бы использовать `max-width: 1200px` или `min-width: 1200px`.
